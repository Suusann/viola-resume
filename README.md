# Viola ZHENG · 中提琴演奏简历

中提琴演奏者 Viola ZHENG(郑妍佳)的个人简历互动网页。

## 简历内容

- 🎻 演奏经历:上海交通大学、南洋理工大学、上海交大校友乐团
- 🏛️ 演出场地:上海东方艺术中心、上海交响乐团新厅、上海音乐厅
- 🎼 合作乐团:上海爱乐乐团、上海城市交响乐团、慕尼黑工业大学交通乐团
- 🎭 合作指挥:曹鹏、林友声、张洁敏、吴一波、宓多里
- 🎪 音乐节:辰山草地音乐节、MISA、上海之春
- 🏆 获奖:2018 大学生艺术展演金奖
- 🎵 独奏录音片段
